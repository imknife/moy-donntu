# Мой ДонНТУ

Неофициальное приложение с расписанием для студентов ДонНТУ.

## Что умеет

- Расписание группы: день, неделя, месяц, замены и отменённые пары.
- Поиск групп, преподавателей и аудиторий, свободные аудитории.
- Пара на экране блокировки, напоминания, виджет.
- Дедлайны и заметки.
- Зачётная книжка, студенческий билет и лента кабинета ACE: пароль не сохраняется, токен хранится на телефоне и уходит только в ACE.
- Работает без сети.

## Сборка

Нужны Flutter stable, Android SDK и Java 21.

```
flutter pub get
flutter build apk --debug
```

Для release скопируйте `android/key.properties.example` в `android/key.properties` и укажите свой ключ: без него release не соберётся. Адрес сервера задаётся при сборке: `--dart-define=API_URL=https://...`.
