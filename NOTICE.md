# Сторонние материалы

Лицензия MIT из файла [LICENSE](LICENSE) относится только к коду приложения. Материалы ниже входят в него со своими условиями.

| Материал | Лицензия | Где лежит |
| --- | --- | --- |
| Шрифт Onest | SIL Open Font License 1.1 | `assets/fonts/`, текст лицензии: `assets/fonts/LICENSE_Onest.txt` |
| Значки Lucide (`lucide_icons_flutter`) | ISC; часть значков восходит к Feather (MIT, Cole Bemis) | `assets/fonts/LucideSubset.ttf` |
| Пакеты Flutter и pub.dev | свои лицензии у каждого пакета | подключаются через `pubspec.yaml` |
| Снимок расписания и список преподавателей | данные из расписания, опубликованного университетом; права на данные остаются у их владельцев | `assets/seed/` |

## Шрифт

Из вариативного файла Onest вырезаны статические начертания 400, 500, 600 и 700 без italic, оставлены латиница, кириллица и знаки (`tool/subset_fonts.py`).

## Значки

Из Lucide собран урезанный набор, в него вошли только значки, которые использует приложение.
